CONFIGURE PARKING SLOTS

Calibrate once.
Analyse every frame.

Run the existing desktop calibration tool from the project folder with your local video. Click slot corners, press Enter to finish each polygon, then S to save.

.\.venv\Scripts\python.exe scripts/setup_parking_slots.py --input "parking.mp4" --output "config/parking_slots.json"

Replace parking.mp4 with your video's path. Upload the saved JSON here. Recalibrate if the camera or resolution changes.
